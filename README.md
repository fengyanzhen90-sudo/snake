# Snake Game

一个单文件 HTML 贪吃蛇游戏，可直接通过 GitHub Pages 发布。

## 本地打开

双击 `index.html`，或用浏览器打开：

```text
file:///D:/23073/Documents/ai_coding/snake/index.html
```

## GitHub Pages

将本仓库推送到 GitHub 后，在仓库的 `Settings -> Pages` 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

保存后等待 GitHub 生成公开网址。
